# LOL 智能分组

一个用于 LOL（英雄联盟）开黑的“分组 + 抽英雄”工具：先把 10 人公平分成蓝红两队，
再按照每个人分到的位置，从 OP.GG 的英雄榜快照里自动抽 1~3 个英雄（默认每人 2 个）。

在线演示：[youngzhou6.space](https://youngzhou6.space)

> 📦 当前版本：**v1.7**（2026-09-16）｜版本公告见 [CHANGELOG.md](CHANGELOG.md)
>

## ✨ 功能特性

### 分组

- 🎯 **智能平衡**：根据玩家在该位置的加权 ELO 自动平衡两队实力，让双方加权总分尽量接近
- ⚖️ **ELO 位置权重**：上单 / AD ×0.95，中单 / 打野 ×1.05，辅助 ×1.00；队伍卡片同时展示原始 ELO 和加权 ELO
- 🔀 **真随机**：完全随机分组，位置随机、队伍随机，看谁运气好
- 🔒 **位置锁定**：每个玩家可同时锁定多个位置，系统只在锁定位置内分配，避免位置跑偏
- 🤝 **同队约束**：支持指定任意两名玩家“必须同队”或“不要同队”，两种分组模式都会遵守
- 📊 **实时对比**：分组后显示双方原始 ELO、加权 ELO、分差、估算胜率与实力评级

### 抽英雄

- 🎮 **按位置自动抽英雄**：分组结果确定后，每位玩家从自己分到的位置池中随机抽英雄，
  数量可在 1~3 之间滑动调整（默认每人 2 个）
- 🗂️ **三种英雄池**：
  - `全英雄`：该位置 OP.GG 榜单全部英雄
  - `热门前 20`：OP.GG 榜单前 20 名
  - `Tier 1~2`：OP.GG 版本强势英雄（Tier 1~2）
- 🚫 **全场英雄不重复**：同一局不会出现重复英雄，也不会有人拿到重复的英雄
- ⚖️ **跨位置公平去重**：同一个英雄如果同时出现在多个位置池（如剑魔可上单/打野），
  被某个位置抽到后，其他位置池会同步排除，不会出现两边都抽到剑魔的情况
- 🎲 **重新抽英雄**：点击后只重抽英雄，不改变队伍和位置
- 👁️ **英雄池预览**：点击顶部「英雄池」可查看当前池子每个位置包含的英雄（头像 + 中文名）

### 数据与体验

- 📦 **OP.GG 版本快照**：英雄数据在构建时写入项目，页面会标注
  “Patch 版本 / 分段 / 数据更新时间”，版本更新后跑一条命令即可刷新

- 选人页卡片是**统一尺寸**（`PLAYER_CARD_WIDTH` / `PLAYER_CARD_HEIGHT`，默认 132×72），
  名字长短、有无标签都不改变卡片大小；超长名字显示省略号，悬停可看全名
- 卡片上只显示第一个标签 chip，多标签以 `+N` 表示，悬停查看全部

**标签规则**：

- 预设标签：`咕咕嘎嘎`、`精英咕咕嘎嘎`、`ikun翡翠兄弟`、`ikun战神`、`再次抽象`、`水豚噜噜`

  颜色多了反而花。想换主题色只改 `lib/players/tags.ts` 里的 `TAG_COLOR`
- 清洗规则：去掉首尾空白与控制字符、自动去重、最长 8 个字符、每人最多 5 个

### 🧑‍💻 临时玩家与本地缓存

- 点「➕ 添加玩家」填入名字与五个位置的档次即可加入，会保存在浏览器 `localStorage`
- 选人页顶部有独立的「临时玩家」区块，显示人数并提示“仅保存在本机浏览器”
- **逐个删除**：点每个临时玩家 chip 上的 `✕`
- **一键清空**：点区块右上角「🗑️ 全部删除」（需要二次确认）
- 删除时会一并清理该玩家的选中状态、位置锁定、同队约束、英雄抽取结果与标签，不留孤儿数据
- 标签随玩家记录一起存（`lol:custom-players:v1`），不需要额外的覆盖层
- 缓存损坏（手改、字段缺失、非法档位、重名）时逐条丢弃坏数据，页面对应位置回退到默认状态
- 若浏览器禁用 localStorage（隐私模式等），会静默降级为“本次会话内有效”，不报错
- ⚠️ 只存在本机：换设备、换浏览器、清缓存都会丢失；基础 39 人名单仍然来自 `data/players.ts`

- 搜索词与标签之间也是**交集**，可以叠加使用（如选中「咕咕嘎嘎」再搜「大灰蛛」）

## 🎮 使用流程

1. **选择 10 位玩家**：点击玩家卡片选中，已选人数显示在左上角（10/10 时才能开始分组）
   - 玩家多时可先**搜索 id** 或**按标签筛选**快速定位（详见「🔍 搜索与标签筛选」）
2. **锁定位置（可选）**：在每个玩家的位置卡片里点击位置按钮，可同时锁定多个位置
3. **设置同队约束（可选）**：选择两名玩家，添加“必须同队”或“不要同队”
4. **选择分组模式**：
   - `智能平衡`：按位置加权 ELO 自动均衡双方实力（默认阈值 10%）
   - `真随机`：只保证能组成 5v5，不做实力均衡
5. **设置抽英雄规则（可选）**：
   - 选择英雄池：`全英雄 / 热门前 20 / Tier 1~2`，默认全英雄
   - 拖动「每人英雄数」滑条：可设为 1~3 个，默认 2 个
6. **点击「⚔️ 开始分组」**：系统同时完成“分组 + 抽英雄”
7. **查看与重抽**：每人名下显示对应数量的英雄卡片（头像 + 中文名 + 胜率/登场率，
   悬停可看 OP.GG 排名）；点「🎲 重新抽英雄」只重抽英雄，队伍和位置保持不变
8. **切换规则**：分组后修改英雄池或每人数量会立即按新规则重抽；
   点击「英雄池」下的「👁 查看英雄」可预览每个位置的可选英雄

## 🧠 算法原理

### 一、分组算法

#### 目标

把 10 人分成蓝红两队（每队 5 人、五个位置各一人），在满足位置约束的前提下，
让两队按位置加权后的 ELO 总分差尽量小；同时不让位置分配固定偏向某个人或某个弱位置。

#### 分配流程

1. 先把 10 人随机匹配到 10 个位置名额上（每个位置恰好 2 人，蓝/红各一个）
2. 有位置锁定时，只允许玩家被分到锁定的位置
3. 每个位置的两个候选人分别进入蓝方和红方，枚举 32 种蓝红切分，
   先过滤掉不满足“必须同队 / 不要同队”约束的切分，再找出加权 ELO 分差最小的组合
4. 重复生成多套位置分配，收集所有分差满足阈值的结果，再随机返回其中一套

这样做的好处：ELO 只决定“队伍怎么切”，不再反过来决定“把谁塞到哪个位置”，
所以像羊羊这种多位置玩家不会因为打 ADC 分低而总被算法安排成 ADC。

#### ELO 位置权重

玩家的原始 ELO 来自其分到位置的档次，分组前会先乘以位置权重：

| 位置 | 权重 |
|---|---|
| 上单 | 0.95 |
| AD | 0.95 |
| 中单 | 1.05 |
| 打野 | 1.05 |
| 辅助 | 1.00 |

例如某玩家中单 ELO 为 160，则加权 ELO 为 `160 × 1.05 = 168`。
蓝红切分和最终分差都使用加权 ELO 计算，结果卡片会同时显示原始 ELO，方便核对。

#### 两种模式

- `智能平衡`：随机生成最多 300 套位置分配，每套内部再做蓝红最优切分；
  从所有分差 ≤ 阈值（默认 10%）的阵容里随机挑一套，找不到则返回分差最小的一套
- `真随机`：位置随机分配，蓝红双方也随机，只要 10 人能组成完整阵容就输出结果

#### ⚠️ 阈值实际约束了什么（实测）

这一点容易误解，先说结论：

1. **它只管「队伍总分差」，不管每条路的分差。**
2. **无位置锁定时它几乎不生效。** 5 个位置各 2 人、共 32 种蓝红切分，让“总分差”变成了一个
   很容易精确凑到 0 的子集和问题——实测 300 次位置配对内，60/60 组都能凑出总分差 **恰好 0**，
   于是 1% / 3% / 5% / 10% / 20% / 60% 所有阈值的达成率都是 **100%**，
   滑杆拉大拉小结果一样。
3. **它在被约束时才真正生效。** 位置锁定或同队约束会压小组合空间，凑不出完美平衡：

   | 场景 | 1% 阈值 | 3% | 5% | 10% |
   |---|---|---|---|---|
   | 无锁定 | 100% | 100% | 100% | 100% |
   | 3 人各锁 1 个最强位 | 60% | 75% | 94% | 100% |
   | 10 人全锁最强位 | 20% | 40% | 100% | 100% |

4. **总分差为 0 ≠ 每条路都公平。** 差距会互相抵消：上单崩 180 分、打野赚回 180 分，总分照样是 0。
   实测同一批“总分差 0”的结果里，**单路最大分差 P50 = 63 分、最高可达 158 分（≈ 5 个档位）**。

想真正做“对线级公平”，需要把目标函数从「总分差」改成同时考虑每条路的分差（见
[OPTIMIZATION.md](OPTIMIZATION.md) 的 P2-3），目前尚未实现。

#### 同队约束

- `不要同队`：两人必须分在蓝红不同队
- `必须同队`：两人必须分在同一队
- 同一位置的两人天然分在不同队，因此无法设置“必须同队”
- 如果多条约束互相冲突，或与位置锁定一起导致无解，页面会提示分组失败

#### 为什么不能保证一定成功？

10 个人都要分配 5 个位置之一，且每个队伍每个位置只能有一个人。
如果可用位置不足、位置锁得太多，或同队约束互相冲突，可能凑不齐满足条件的阵容，
此时会提示失败，建议取消部分位置锁定、调整同队约束、更换玩家或切换到真随机。

### 二、英雄抽取算法

#### 目标

分组结果确定后，每个玩家从“自己位置的英雄池”里抽英雄；
每人抽 1~3 个（默认 2），所有玩家拿到的英雄全部不重复。

#### 抽取流程

1. 根据当前选择的英雄池，取出每个位置的可选英雄列表
2. 每次尝试前随机打乱 10 位玩家的顺序，避免“固定先选上单、再选打野”导致的先后手偏差
3. 轮到某位玩家时，从他位置池的剩余英雄中随机取“所需数量”个
4. 抽过的英雄用唯一 key 全局标记；即使他同时属于其他位置池，也不会再被抽到
5. 如果某次顺序导致有人凑不满所需数量，就整局重试；最多 400 次
6. 400 次仍无法凑齐“10 × 每人数量”个不重复英雄时，直接报错提示切换更大的英雄池，
   不会偷偷允许重复

#### 几个容易混淆的点

- **一个英雄能打多个位置**：数据里同一英雄会出现在多个位置池（例如剑魔在上单、打野榜都出现）。
  系统按英雄身份去重，而不是按“位置池”去重，所以跨位置也不会撞车
- **同位置两人**：每个位置有两个人，若每人抽 N 个，该位置就需要凑出 2N 个不同英雄，
  再随机分给两人
- **为什么重新打乱**：先被处理的人选择空间更大，每次尝试都重新打乱，
  等于每个位置都有机会“先选”，避免某个位置固定占便宜
- **英雄池大小会影响概率**：池子越小，池内每个英雄被抽中的概率天然越高，
  这是符合直觉的随机结果，不是先后手 bug

## 🔄 英雄数据如何更新

英雄榜数据以**快照**形式提交在仓库里（`data/champions.ts`），
页面运行时完全不依赖 OP.GG，访问快速稳定。

### 什么时候需要更新

英雄联盟每次版本更新（通常每两周左右）后，OP.GG 榜单会变化。
想使用最新数据时手动更新一次即可。

### 更新命令

```bash
npm run update:champions
```

脚本会依次请求 OP.GG 的上单 / 打野 / 中单 / AD / 辅助五个页面，
解析出每个位置的英雄榜，连同 `Patch 版本 / 服务器 / 分段 / 抓取时间`
一起写回 `data/champions.ts`。

更新完成后重新构建部署：

```bash
npm run build
```

> 页面底部信息会自动变成类似：
> `🎮 英雄数据来自 OP.GG · Patch 16.17 · 单双排 · 全服 · 翡翠+ · 更新 2026-09-04`

> ⚠️ 更新命令需要联网访问 OP.GG。如果 OP.GG 日后改版导致解析失败，
> 脚本会报错并停止，不会覆盖旧快照，页面仍可正常使用旧数据。

### 快照里包含什么

每个位置保存约 40~60 个英雄，每个英雄记录：

- `key`：英雄唯一标识（用于跨位置去重）
- `name`：中文名
- `imageUrl`：头像 CDN 地址
- `tier` / `rank`：OP.GG 评级与排名
- `winRate` / `pickRate` / `banRate`：胜率 / 登场率 / 禁用率

> 相邻档位统一相差 30 分，按标准 ELO 公式对应约 **54% 单人胜率**——足以体现差距，
> 又不至于让低档玩家毫无体验。实测本表 39 位玩家：队伍加权总分均值约 **576**。
>
> 补充一个实测结论：因为 5 个位置各有 2 人（共 32 种切分），算法在 300 次尝试内
> **几乎总能凑出恰好 0 分差的完美五五开**，所以「加权 ELO 差值阈值」实际很少成为约束条件，
> 更多是位置锁定或同队约束导致无法完美平衡时的兜底。

### Cloudflare 静态托管 + 阿里云域名

## ❓ 常见问题

**Q: 为什么分组会失败？**

10 人需要组成两套完整五位置阵容，位置不够或锁定太多时可能无解。可以：

- 取消部分位置锁定
- 更换几个玩家
- 切换到「真随机」模式
- 调高加权 ELO 差值阈值

**Q: 抽英雄会出现重复吗？**

不会。算法全局按英雄唯一标识去重，无论是同一位置两人、还是跨位置都能打同一个英雄，
任何位置都不会撞车；如果实在凑不齐“10 × 每人数量”个不重复英雄，会报错提示，
不会退回“允许重复”的结果。

**Q: 抽英雄报错“凑不出足够多不重复英雄”怎么办？**

说明当前英雄池太小（通常出现在 `Tier 1~2`）。切换到 `全英雄` 或 `热门前 20`
后重新抽即可；也可以把「每人英雄数」调小，或点「🎲 重新抽英雄」多试几次。

**Q: 英雄数据过时了怎么办？**

运行 `npm run update:champions` 更新快照，然后重新构建部署。
页面显示的数据版本就是当前快照的 Patch，一眼能看出新旧。

**Q: 为什么同一个英雄在多个位置都能看到？**

因为该英雄确实能打这些位置（例如剑魔 = 上单/打野）。抽英雄时会全局去重，
这个英雄一旦被某个位置抽走，就不会再分给另一个位置的人。

**Q: 如何修改玩家的档次？**

编辑 `data/players.ts` 中的 `TIER_INFO`（影响 ELO 值、颜色、图标）或
`PLAYERS` 数组中的玩家位置配置。
